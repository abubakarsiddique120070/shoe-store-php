# 👟 Shoe Store Management System

A complete web-based shoe store management system.

## Features
- Admin & Manager login system
- Product & category management
- Order tracking
- Customer complaints
- Payment methods

## Technologies Used
- PHP
- MySQL
- HTML & CSS

## How to Run
1. Import database.sql in phpMyAdmin
2. Configure db.php with your credentials
3. Run on localhost with XAMPP
